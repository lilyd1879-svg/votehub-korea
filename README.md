# 🗳️ VoteHub Korea (보트허브 코리아)

> **대한민국 254개 국회의원 선거구 인터랙티브 지도 & 역대 9대 전국 선거 전수 읍면동 개표 분석기 (2016–2028)**

순수 웹 브라우저 환경에서 동작하는 고해상도 벡터 SVG 기반 대한민국 선거구 인터랙티브 시각화 및 실시간 시뮬레이션 플랫폼입니다.

## ✨ 핵심 기능

1. **전국 254개 지역구 정밀 인터랙티브 지도**:
   - 중앙선거관리위원회 선거구 획정안(제22대 총선 기준) 기반 254개 선거구 경계 벡터 SVG 렌더링
   - 권역별(수도권, 충청권, 호남권, 대구·경북, 부산·울산·경남, 강원·제주) 스마트 줌 및 초점 포커스

2. **역대 9대 전국 선거 전수 개표 데이터 수록**:
   - 제20대 국회의원 선거 (2016)
   - 제19대 대통령 선거 (2017)
   - 제7회 전국동시지방선거 (2018)
   - 제21대 국회의원 선거 (2020)
   - 제20대 대통령 선거 (2022)
   - 제8회 전국동시지방선거 (2022)
   - 제22대 국회의원 선거 (2024)
   - 제9회 전국동시지방선거 (2026)
   - 제23대 국회의원 선거 예측 (2028)

3. **읍·면·동 단위 초미세 득표 분석**:
   - 전국 수천 개 읍·면·동별 정당별 득표율, 표차, 득표수 툴팁 및 상세 분석 카드 제공
   - 선거별 격전지(스윙 보터) 및 득표율 스윙(Swing) 변동 분석

4. **실시간 선거 시뮬레이터 (2028 총선 예측)**:
   - 정당별 지지율 스윙 슬라이더 실시간 조작
   - 지지율 변동에 따른 의석수 실시간 재집계 및 지도 색상 동적 반영

## 🛠️ 기술 스택
- **Architecture**: Single File Self-Contained Web Application (Zero External Dependencies)
- **Styling**: Tailwind CSS, CSS Grid/Flexbox
- **Vector Graphics**: Dynamic Interactive SVG Map Context
- **Data Engine**: Optimized In-Memory Embedded EMD Election Matrix
